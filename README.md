## Как запустить тесты
Для запуска всех модульных тестов выполните команду в терминале:
```mvn clean test```

Для запуска эксперимента производительности выполните метод ```main``` в классе ```org.example.CollectionPerformanceExperiment``` через IntelliJ IDEA.

## Выводы по эксперименту производительности
Добавление в конец у обеих коллекций работает за амортизированное время O(1), но ArrayList быстрее, так как пишет данные в непрерывный массив и не тратит время на выделение памяти под новый узел Node на каждый элемент.

Добавление в начало и удаление из начала у LinkedList работают намного быстрее (за O(1)), потому что список просто меняет ссылки первого узла.

В ArrayList добавление в начало и удаление из начала требуют сдвига всех остальных элементов массива вправо или влево через копирование, поэтому каждая такая операция занимает O(n).

Вставка в середину у обеих коллекций работает за O(n), но ArrayList оказывается быстрее: сдвинуть половину массива в памяти быстрее, чем в LinkedList шагать по ссылкам через половину элементов, разбросанных в разных местах памяти.

Последовательный доступ по индексу get(i) в ArrayList выполняется мгновенно за O(1) за счет прямого обращения к ячейке массива, а в LinkedList каждый вызов get(i) заново идет по узлам от начала или конца списка за O(n), из-за чего весь цикл замедляется до O(n^2).

Удаление из конца в обеих коллекциях работает быстро за O(1): ArrayList убирает последний элемент без сдвига массива, а LinkedList просто меняет ссылку на последний узел.
